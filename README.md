# Macro-Commodity Volatility Forecasting and Dynamic Maximum Diversification

This repository contains the complete quantitative research pipeline developed for a BSc Hons Mathematics research internship. The project implements a crisis-aware asset allocation framework by replacing static historical covariances with time-varying forecasts generated by an ARIMAX-DCC-GARCH engine, optimized via Maximum Diversification (MD).

## Project Structure
* **`01_data_extraction.py`**: The main execution script containing the full pipeline (Data Ingestion, Preprocessing, ARIMAX Modeling, EGARCH-DCC Forecasting, SLSQP Optimization, Performance Analytics, Visualization, and Automated PDF Reporting).
* **`Maximum_Diversification_Report.pdf`**: The generated institutional-grade analytical report complete with risk metrics and target allocations.
* **`Chart_*.png`**: Econometric diagnostic charts (Stationarity, ACF/PACF, and Cumulative Drawdowns).

## Methodology Roadmap
1. **Universe Construction**: Ingestion of multi-asset historical data via Yahoo Finance (`yfinance`) and FRED APIs.
2. **Preprocessing**: Calendar alignment, Last Known Value (LKV) interpolation, and logarithmic return transformation.
3. **Mean Modeling**: ARIMAX grid search optimized via Bayesian Information Criterion (BIC) with macro exogenous variables (DXY, VIX).
4. **Volatility Forecasting**: Univariate EGARCH(1,1) modeling for asymmetric leverage effects followed by Dynamic Conditional Correlation (DCC).
5. **Portfolio Optimization**: Maximizing the Diversification Ratio (DR) using the SLSQP algorithm under long-only and concentration constraints.
6. **Reporting**: Automated compilation of analytics, tables, and charts into a styled PDF via ReportLab.
